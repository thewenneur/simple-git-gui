**Simple Git 0.1.0** is the first release: a Git interface for people who don't know
Git, that still shows every `git` command it runs.

Simple Git needs [Git](https://git-scm.com) installed on the computer.

## Download

| System | File | How to install |
| --- | --- | --- |
| Windows | `simple-git-gui-0.1.0-windows-x86_64-setup.exe` | Run it. It installs for you only, without administrator rights, adds Simple Git to the Start menu and to the `PATH`. |
| Windows (no install) | `simple-git-gui-0.1.0-windows-x86_64-portable.exe` | Put it anywhere, for example on a USB key, and double-click it. |
| macOS (Apple Silicon and Intel) | `simple-git-gui-0.1.0-macos-universal.dmg` | Open it and drag Simple Git onto Applications. The first time, right-click the app and choose **Open** (it is not notarized by Apple). |
| Linux | `simple-git-gui-0.1.0-linux-x86_64.AppImage` | Make it executable (`chmod +x`) and run it. |
| Linux | `simple-git-gui-0.1.0-linux-x86_64.tar.gz` | Extract it and run `./install.sh` to add it to your applications menu (no root needed). |

To open a folder from a terminal with `simple-git-gui .`: the Windows installer and the
Linux `install.sh` set up the command; on macOS, double-click **Install Terminal
Command** in the `.dmg`.

Windows may show a SmartScreen warning because the files are not signed yet: choose
**More info**, then **Run anyway**.

## What you can do

- **See and save your changes**: changed files in plain words, readable diffs (side by
  side, moved lines shown as moved, VHDL, Verilog, Tcl and more colored), then save a
  step (commit) with a short summary and, if needed, a longer description.
- **Get and Send**: Simple Git always gets your colleagues' work before sending yours,
  and shows what will go to the server first.
- **Undo anything** with Ctrl+Z until you send.
- **Branches**: a graph of every branch; drag a commit or a branch to merge, move or copy
  it, always with a confirmation showing the git command.
- **Conflicts** explained with branch names instead of "ours" and "theirs", with fewer
  false conflicts.
- **Submodules**, **file locks** (Git LFS), **workspaces** (git worktrees) and ready-made
  `.gitignore` rules for Vivado, Quartus, ModelSim, KiCad and more.
- **A tutorial** on a practice repository, offered on first launch and available from
  the **?** button.
- **Git settings explained**, including where server passwords are kept, and a one-click
  fix for files whose Windows and Linux line endings got mixed.
- English and French, light and dark themes.

For experienced users: the Git log panel lists every command run, and advanced mode
adds a console to type your own commands.

Simple Git is written with heavy use of AI (Claude, by Anthropic), directed by its
maintainer: see the README's AI usage disclosure.
